## 管理员用户管理：表单增加密码字段 + 后端默认密码逻辑

### 需求
- 表单新增密码字段（InputPassword）
- 创建时若密码为空，后端使用默认密码 `123456`
- 编辑时密码为空不修改，有值时更新

### 修改清单

```proto
string password = 8 [(gnostic.openapi.v3.property) = {description: "密码（可选）"}];
```

#### 4. data - app/admin/service/internal/data/admin.go

### 关键知识点
- **Vben Form 密码组件**：`component: 'VbenInputPassword'`（不是 `'InputPassword'`，参考 `views/_core/authentication/login.vue` 和 `views/_core/profile/password-setting.vue`）
- **ent SetPassword 跳过策略**：用 builder 模式累加 SetXxx，最后判断是否调用 SetPassword，避免每次 update 都覆盖密码
- **biz/data 分工**：biz 层处理默认值（创建时默认密码），data 层处理条件更新（编辑时空跳过），各司其职
- **proto 字段编号**：UpdateAdminRequest 现有字段 1-7 + 20，password 分配编号 8；20 留给 roleIds（业务约定）
- **Sensitive 字段**：ent schema `field.String("password").Sensitive()` 标签让 JSON 序列化跳过 password，
  前端 GetAdmin API 不会收到 password 字段，编辑表单密码框保持空白（安全）
