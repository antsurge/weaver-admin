# 2026-07-22 工作日志

## 项目技术分析

完成了 Weaver-Admin 项目的全面技术分析，包括：

1. **后端技术栈**：Go + Kratos v2.9.2 微服务框架 + Ent ORM + Protobuf/gRPC/HTTP 双协议
2. **前端技术栈**：Vue Vben Admin (Vue 3.5 + TypeScript + Ant Design Vue + Vite + Turborepo Monorepo)
3. **分层架构**：Kratos 标准四层架构（Server → Service → Biz → Data）
4. **认证机制**：JWT 双 Token 机制（Access Token 2h + Refresh Token 7d）+ Redis 存储
5. **基础设施**：MySQL + Redis + RabbitMQ | Google Wire 依赖注入 | Buf Validate 参数校验
6. **工程化**：Proto-First 设计 | 自动化代码生成 | 完整的国际化支持

项目特点：DDD 领域驱动设计、企业级安全机制、Monorepo 管理、生产级代码规范

3. **自动回显**：编辑角色时自动加载并勾选已绑定的菜单
4. **懒加载**：菜单树只在首次打开弹窗时加载
5. **用户体验**：
   - 默认展开所有节点
   - 最大高度 400px + 滚动条
   - 加载状态提示
   - 空数据提示

### API 调用流程

```
打开编辑弹窗 → loadMenuTree() → GET /admin/v1/menu/tree
              ↓
         编辑模式？→ getRoleApi(id) → GET /admin/v1/role/{id}
              ↓                    ↓
         回显 menuIds      设置表单值 + 勾选 Tree
              ↓
用户修改 + 点击保存
              ↓
    updateRoleApi(id, data) → PUT /admin/v1/role/{id}
    bindMenusForRoleApi(id, keys) → PUT /admin/v1/role/{id}/menus
              ↓
         关闭弹窗 + 刷新列表
```
