## 修复 VbenForm 自定义组件 FormTitle 不渲染问题

### 问题描述
在 VbenFormSchema 中使用自定义组件 `FormTitle`，但组件无法渲染展示。

### 根因分析
Vben Form 有两套独立的组件注册机制：
1. **Vue 全局注册** (`app.component()`) - 仅用于 Vue 模板
2. **Vben 组件注册** (`globalShareState.setComponents()`) - Vben Form 内部使用

用户错误地在 `bootstrap.ts` 中使用了 Vue 全局注册，但 Vben Form 的 schema 渲染器从 `globalShareState` 查找组件，导致找不到 `FormTitle`。

### 修复方案
修改 **`adapter/component/index.ts`** 文件：
1. 导入 FormTitle 组件（第 42-43 行）
2. 在 `ComponentType` 类型定义中添加 `'FormTitle'`（第 500 行）
3. 在 `components` 对象中注册 `FormTitle`（第 557-558 行）

### 清理工作
移除 `bootstrap.ts` 中冗余的 FormTitle 导入和 `app.component()` 注册

### 修改的文件
- `frontend/apps/web-antd/src/adapter/component/index.ts` - 主要修复文件
- `frontend/apps/web-antd/src/bootstrap.ts` - 清理冗余代码

### 关键知识点
**Vben Admin 自定义组件注册规范：**
- 所有用于 VbenForm/VbenModal/VbenDrawer 的自定义组件必须在 `adapter/component/index.ts` 中注册
- 需要同时在 `ComponentType` 类型和 `components` 对象中添加
- 不要在 `bootstrap.ts` 中使用 `app.component()` 注册表单组件（无效）

## 调整 FormTitle 组件位置（占据整行）

### 问题描述
FormTitle 组件在表单中显示时，左边有 label 的位置占用空间，导致组件不能靠左对齐到容器边缘。

### 解决方案
在 FormTitle 的 schema 配置中添加三个属性：
- `label: ''` - 隐藏 label 文本
- `labelWidth: 0` - 去掉 label 占用的宽度（覆盖全局的 70px 设置）
- `formItemClass: 'col-span-2 md:col-span-2'` - 明确指定占据整行

### 修改文件
- `frontend/apps/web-antd/src/views/permission/menu/modules/form/index.vue` (第 65-74 行)

### 关键知识点
**VbenForm Schema 单项配置优先级高于 commonConfig：**
- 可以针对单个表单项覆盖全局的 `labelWidth`
- 使用 `formItemClass` 可以控制单个项的布局类名
- 对于不需要 label 的展示性组件（如标题、分隔符），设置 `labelWidth: 0` 效果最佳

## 重新组织菜单管理表单布局（第一步）

### 需求描述
1. 将类型、上级菜单、菜单名称、菜单编码、权重、图标放到"基础设置"分组下
2. 基础设置下除了类型和上级菜单，其他字段两个字段为一行
3. type为按钮的时候不需要展示图标

### 实现方案

**字段布局调整：**

| 字段 | 布局 | 说明 |
|------|------|------|
| **基础设置** (FormTitle) | `col-span-2` | 分组标题 |
| **类型** (type) | `col-span-2` | 占据整行 |
| **上级菜单** (parentID) | `col-span-2` | 占据整行 |
| **菜单名称** (name) | `col-span-1` | 一行左半 |
| **菜单编码** (code) | `col-span-1` | 一行右半 |
| **权重** (weight) | `col-span-1` | 一行左半 |
| **图标** (icon) | `col-span-1` | 一行右半（按钮类型时隐藏） |
| 其他字段 | `col-span-2` | 保持整行 |

**关键技术点：**
- 使用 `formItemClass: 'col-span-1 md:col-span-1'` 让字段占据半行
- 图标字段的 `dependencies.show` 控制在按钮类型时隐藏
- 保留其他原有逻辑不变
