## 修复 VbenForm 自定义组件 FormTitle 不渲染问题

### 问题描述
在 VbenFormSchema 中使用自定义组件 `FormTitle`，但组件无法渲染展示。

### 根因分析
Vben Form 有两套独立的组件注册机制：
1. **Vue 全局注册** (`app.component()`) - 仅用于 Vue 模板
2. **Vben 组件注册** (`globalShareState.setComponents()`) - Vben Form 内部使用

用户错误地在 `bootstrap.ts` 中使用了 Vue 全局注册，但 Vben Form 的 schema 渲染器从 `globalShareState` 查找组件，导致找不到 `FormTitle`。

### 修复方案
修改 **`adapter/component/index.ts`** 文件：
1. 导入 FormTitle 组件（第 42-43 行）
2. 在 `ComponentType` 类型定义中添加 `'FormTitle'`（第 500 行）
3. 在 `components` 对象中注册 `FormTitle`（第 557-558 行）

### 清理工作
移除 `bootstrap.ts` 中冗余的 FormTitle 导入和 `app.component()` 注册

### 修改的文件
- `frontend/apps/web-antd/src/adapter/component/index.ts` - 主要修复文件
- `frontend/apps/web-antd/src/bootstrap.ts` - 清理冗余代码

### 关键知识点
**Vben Admin 自定义组件注册规范：**
- 所有用于 VbenForm/VbenModal/VbenDrawer 的自定义组件必须在 `adapter/component/index.ts` 中注册
- 需要同时在 `ComponentType` 类型和 `components` 对象中添加
- 不要在 `bootstrap.ts` 中使用 `app.component()` 注册表单组件（无效）

## 调整 FormTitle 组件位置（占据整行）

### 问题描述
FormTitle 组件在表单中显示时，左边有 label 的位置占用空间，导致组件不能靠左对齐到容器边缘。

### 解决方案

- `labelWidth: 0` - 去掉 label 占用的宽度（覆盖全局的 70px 设置）

### 修改文件
- `frontend/apps/web-antd/src/views/permission/menu/modules/form/index.vue` (第 65-74 行)

### 关键知识点
**VbenForm Schema 单项配置优先级高于 commonConfig：**
- 可以针对单个表单项覆盖全局的 `labelWidth`
- 使用 `formItemClass` 可以控制单个项的布局类名
- 对于不需要 label 的展示性组件（如标题、分隔符），设置 `labelWidth: 0` 效果最佳

## 修复 @iconify/json 浏览器兼容性问题

### 问题描述
使用 `@iconify/json` 包时报错：`TypeError: (0 , import_url.fileURLToPath) is not a function`

### 根因分析
`@iconify/json` 是为 Node.js 设计的包，依赖 `url.fileURLToPath` 和 `fs` 等 Node API，无法在浏览器/Vite 环境中使用。

### 修复方案
改用 Iconify HTTP API (`https://api.iconify.design/collection?prefix=xxx`) 获取图标数据，完全兼容浏览器环境。

## 修复 EnhancedIconPicker 导入路径错误

### 问题描述
EnhancedIconPicker 组件报错：
1. `Failed to resolve import "@vben-core/shadcn-ui"` - 无法解析包路径
2. `@vben/common-ui does not provide an export named 'VbenIcon'` - 导出不存在

### 根因分析
**Vben Admin monorepo 包依赖层级：**
```
apps/web-antd/src/          ← 应用层代码
  └─ @vben/common-ui        ✅ 可访问（应用直接依赖）
      └─ @vben-core/shadcn-ui ❌ 不可访问（内部包别名）
          └─ VbenIcon, VbenPopover, VbenIconButton 等组件
```

`@vben-core/shadcn-ui` 是 **monorepo 内部路径别名**，只在 `packages/` 目录下的包之间通过 `workspace:*` 依赖生效。应用层（`apps/web-antd/src/`）无法直接解析此路径。

同样，`VbenIcon`、`VbenPopover`、`VbenIconButton` 等组件虽然被 `@vben/common-ui` 的内部文件使用，但**没有从 `@vben/common-ui/index.ts` 导出**。

### 修复方案

**完全使用 ant-design-vue 和 @iconify/vue 替代：**

| 原组件 | 替换为 |
|--------|--------|
| `VbenPopover` (shadcn-ui) | `Popover` (ant-design-vue) |
| `VbenIcon` (shadcn-ui) | `Icon` (@iconify/vue) |
| `VbenIconButton` (shadcn-ui) | `Tooltip` + `Button` (ant-design-vue) |
| `Tabs/TabsList/TabsTrigger` (shadcn-ui) | `Tabs/TabPane` (ant-design-vue) |
| `Pagination*` (shadcn-ui) | `Pagination` (ant-design-vue) |
| `Button/Input` (shadcn-ui) | `Button/Input` (ant-design-vue) |

**额外修改：**
1. 在 `package.json` 添加 `@iconify/vue: "catalog:"` 依赖
2. 运行 `pnpm install` 安装新依赖

### 修改的文件
1. **`frontend/apps/web-antd/src/components/icon-picker/enhanced-icon-picker.vue`** - 完全重写导入和模板
2. **`frontend/apps/web-antd/package.json`** - 添加 @iconify/vue 依赖

### 关键知识点
**Vben Admin 应用层可用的包：**
- `@vben/common-ui` - 可用，但只导出了部分组件（见 index.ts）
- `@vben/icons` - 可用，导出 EmptyIcon, Grip, listIcons 等
- `@vben/hooks`, `@vben/locales` 等 - 可用
- `@vben-core/*` - **不可用**，这是内部包别名

**应用层 UI 组件推荐使用：**
- `ant-design-vue` - 完整的 Ant Design Vue 组件库
