## 修复表单项 description 导致输入框不对齐问题

### 问题描述
表单项配置了 `description` 后，输入框位置向上偏移。一行两个字段（col-span-1）时，
有 description 和没有 description 的字段输入框顶部不对齐。

### 根因分析
Vben Form 的 `FormItem`（`packages/@core/ui-kit/form-ui/src/form-render/form-field.vue`）结构：

```
FormItem (flex-row + items-center)   ← label 与右侧内容区垂直居中对齐
  ├── FormLabel
  └── div.flex-auto (右侧内容区)
        ├── input wrapper (FormControl + suffix)
        ├── FormDescription            ← 占据文档流空间，使右侧内容区变高
        └── FormMessage (absolute)     ← 错误消息，绝对定位不占空间
```

- 无 description 的字段：右侧内容区高度 = 输入框高度，label 与输入框垂直居中 ✅
- 有 description 的字段：右侧内容区高度 = 输入框 + description，
  `items-center` 使整个内容区居中，输入框相对位置上移 ❌

### 修复方案
在应用层新增全局样式 `frontend/apps/web-antd/src/styles/form.css`，
让 description 绝对定位（与错误消息 FormMessage 相同的处理方式），脱离文档流：

```css
/* description 的 id 由 useFormField 生成：${useId()}-form-item-description */
[id$='-form-item-description'] {
  position: absolute;
}

/* 校验失败时错误消息与 description 位置重叠，优先展示错误消息 */
.form-valid-error [id$='-form-item-description'] {
  visibility: hidden;
}
```

absolute 不指定 top/left 时元素停留在原静态位置（输入框下方），
FormItem 自带的 `pb-4` 底部 padding 已预留空间，不会与下一行重叠。

### 修改的文件
1. **新建** `frontend/apps/web-antd/src/styles/form.css` - 全局修复样式
2. **修改** `frontend/apps/web-antd/src/bootstrap.ts` - 引入 `./styles/form.css`（放在 @vben/styles 之后）

### 关键知识点
**Vben Form FormItem 内部结构（form-field.vue）：**
- 非垂直模式：`flex-row items-center`，label 固定宽度 + 右侧 flex-auto 内容区
- FormDescription 的 id 格式：`${useId()}-form-item-description`，可用属性选择器定位
- FormMessage 本身就是 `absolute` 定位（静态位置 = 输入框下方），FormItem 的 `pb-4` 为其预留空间
- compact 模式下错误消息走 VbenTooltip，不渲染 absolute FormMessage

## 实现 badgeType 清空时 badgeContent 联动清空并禁用

### 需求
菜单管理表单中，当 `badgeType`（徽标类型）未选择或被清空时，
`badgeContent`（徽标内容）需要自动清空值并禁用输入。

### 实现方案
利用 Vben Form `dependencies` 的三个能力组合（`form-render/dependencies.ts`）：
1. `triggerFields` 加入 `'badgeType'`，监听其变化
2. `disabled: (values) => !values.badgeType` - 动态禁用
3. `trigger: (values, formApi) => {...}` - 回调中通过 `formApi.setFieldValue()` 清空值

```typescript
dependencies: {
  triggerFields: ['type', 'badgeType'],
  show: (values) => values.type !== PermissionTypeOptionsValueAction,
  disabled: (values) => !values.badgeType,
  trigger: (values, formApi) => {
    if (!values.badgeType && values.badgeContent) {
      formApi.setFieldValue('badgeContent', undefined);
    }
  },
}
```

### 关键知识点
**Vben Form dependencies 完整能力（dependencies.ts）：**
- `if` - 不渲染 DOM（优先级最高，为 false 时后续逻辑不执行）
- `show` - 隐藏但保留 DOM
- `disabled` - 动态禁用
- `required` - 动态必填
- `componentProps` - 动态组件属性
- `rules` - 动态校验规则
- `trigger(values, formApi)` - 自定义回调，可操作 formApi（setFieldValue 等）
- 所有回调签名：`(formValues, formApi) => any`，支持 async
